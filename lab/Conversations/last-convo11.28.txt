3. BUGS BEGIN APPEARING
------------------------------------------------------------
Multiple problems emerged as enhancements were added:

A) TOOLTIP VALUES DISPLAYED AS "undefined"
- Caused by using incorrect tooltip tokens.
- Needed to use {%open}, {%high}, {%low}, {%close}.
- Fixed successfully afterward.

B) CROSSHAIR / GRIDLINES INCONSISTENT
- Chart sometimes loaded with correct gridlines,
- Other times chart went entirely black.

C) FULL BLACK SCREEN (Blank chart)
- Most serious recurring bug.
- This happened because:
    • plot.xAxis().stroke() is NOT valid in AnyChart Stock charts  
    • chart.legend(false) caused error because stock charts don’t support legend() at chart level  
    • Mis‑placed theme definitions caused internal failures  
    • AnyChart silently fails and renders blank output when encountering invalid API calls

------------------------------------------------------------
4. DIAGNOSTICS & ERROR LOGGING
------------------------------------------------------------
You provided console logs showing:

Error 1:
"Stock chart itself doesn't support legend — stock plots do."

Error 2:
"plot.xAxis(...).stroke is not a function"

Error 3:
"Cannot read properties of null (reading 'enabled')"

These errors indicated:
- Attempting to modify the chart object instead of the PLOT object.
- Attempting to use axis functions not supported on AnyChart Stock.
- Accessing null because theme or plot was initialized at wrong time.

------------------------------------------------------------
5. REPAIRS IMPLEMENTED
------------------------------------------------------------
We systematically removed or corrected:

✓ Removed invalid: chart.legend(false)  
✓ Replaced with: plot.legend(false)

✓ Removed invalid: plot.xAxis().stroke(...)  
✓ Replaced with: plot.xAxis().ticks().stroke() AND plot.xAxis().labels().enabled(false)

✓ Ensured:
    • theme loads BEFORE chart creation  
    • plot is created BEFORE customizing its elements  
    • tooltip is defined AFTER series is created
